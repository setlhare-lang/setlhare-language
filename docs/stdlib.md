# Standard Library Modules

- `std::io`: console I/O
- `std::math`: math functions plus `clamp`, `lerp`
- `std::fs`: file system helpers
- `std::time`: time and sleep
- `std::json`: parse/stringify
- `std::text`: string helpers
- `std::collections` / `col`: chainable `List`, `map`, `filter`, `parallel`
- `std::actors`: `Actor`, `spawn`, `go`
- `net::http`: tiny HTTP server wrapper
- `data::ml`: starter numerical helpers
- `embed`: embedded pin abstraction stub
- `quantum`: toy qubit API stub
- `crypto`: hashing helpers
